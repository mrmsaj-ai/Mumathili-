# Bundled fonts

These Arabic typefaces are used for the Mumathli ad and are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org), which permits bundling
and redistribution.

- **Cairo** — © The Cairo Project Authors (variable weight 200–900). Covers
  Arabic + Latin. Primary display face.
- **Tajawal** — © Boutros™, designed by Mourad Boutros / Arabic Typography.
  Used as a lighter alternate.

They are loaded locally (see `src/mumathli/fonts.ts`) so the render is fully
self-contained — no network fetch and no watermark.
